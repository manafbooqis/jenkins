# Slides Outline — Jenkins Tool CI/CD Basics

## Slide 1: Title
Jenkins Tool — CI/CD Basics
Build a Simple CI Pipeline

## Slide 2: Problem
Manual testing after every code change is slow and error-prone.
Teams need automation to detect bugs early.

## Slide 3: What is Jenkins?
Jenkins is an automation server used in DevOps to automate build, test, and deployment workflows.

## Slide 4: What is CI?
Continuous Integration means frequently merging code changes and automatically validating them using build and tests.

## Slide 5: Project Architecture
Developer → GitHub → Jenkins → Install Dependencies → Run Tests → Build Result

## Slide 6: Pipeline Stages
1. Pull Code
2. Install Dependencies
3. Run Tests

## Slide 7: Live Demo Steps
Show repository, show Jenkinsfile, run Build Now, check Console Output, show success/failure result.

## Slide 8: Challenges and Solutions
Python/pip path issue, GitHub access issue, dependency mismatch, test failure troubleshooting.

## Slide 9: DevOps Value
Automation, faster feedback, fewer manual mistakes, better code quality.

## Slide 10: Conclusion
Jenkins helps teams apply CI by automatically building and testing code after changes.
